# Spacing tokens

## Scale
space-1 4px, space-2 8px, space-3 12px, space-4 16px, space-6 24px, space-8 32px. Use tokens, never raw pixel values.

## Screen margins
Mobile screens use space-4 (16px) horizontal margins. Cards inside lists use space-3 (12px) internal padding.
