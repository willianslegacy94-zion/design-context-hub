# Typography

## Typefaces
Orbit Sans for all interface and marketing text. Orbit Mono only for numbers in statements and account details, so digits align in columns.

## Type scale
Display 40/48, Title 28/36, Heading 20/28, Body 16/24, Caption 13/18. Never set body text below 16px in the app.

## Money values
Currency amounts use tabular figures and the Heading style when they are the main information on a screen.
